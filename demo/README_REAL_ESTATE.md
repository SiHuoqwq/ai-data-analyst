# 析数演示数据 · 房地产销售经营

`real_estate_sales_demo.csv` 是由仓库内
`generate_real_estate_sales_demo.py` 完全生成的合成数据。它不读取、复制
或转换任何现有 Excel、CSV、数据库或用户记录。

## 公开与隐私声明

- 数据为完全合成数据，不包含任何真实公司、楼盘、客户或个人信息。
- 置业顾问使用匿名编号（顾问01 至 顾问12），不出现真实姓名。
- 客户编号为无意义序号（C0001 起），不携带任何可辨识信息。
- 数据仅用于“析数”房地产销售经营分析的产品演示和自动化测试。
- 数据允许随本项目公开展示、复制和分发。

## 数据规模与字段

数据固定为 520 行、14 列，覆盖 2025-01 至 2026-06 共 18 个自然月。
一行代表一条房地产客户销售线索（销售机会），`客户编号` 唯一。

| 字段 | 含义 | 缺失规则 |
|---|---|---|
| 客户编号 | 唯一销售线索编号 | 不允许缺失 |
| 线索日期 | 线索产生日期（ISO 格式） | 不允许缺失 |
| 项目 | 楼盘项目 | 不允许缺失 |
| 城市 | 城市（杭州） | 不允许缺失 |
| 区域 | 行政区域（余杭/滨江/钱塘/萧山） | 不允许缺失 |
| 置业顾问 | 负责顾问（匿名编号） | 不允许缺失 |
| 获客渠道 | 获客渠道 | 不允许缺失 |
| 客户等级 | 客户等级（A/B/C） | 不允许缺失 |
| 到访日期 | 到访日期 | 未到访则缺失 |
| 认购日期 | 认购日期 | 未认购则缺失 |
| 签约日期 | 签约日期 | 未签约则缺失 |
| 户型 | 户型（两房/三房/四房/改善四房） | 不允许缺失 |
| 成交金额 | 合成人民币成交金额 | 未签约则缺失 |
| 回款金额 | 合成人民币回款金额 | 未签约或未回款则缺失 |

日期字段满足漏斗先后约束：`线索日期 ≤ 到访日期 ≤ 认购日期 ≤ 签约日期`；
未到访则后续阶段一律为空，未认购则不得签约。

## 预设趋势

- 短视频平台：线索量最高（约 150 条），但成交转化率最低（5%–9%）。
- 老带新：线索量最低（约 50 条），但成交转化率最高（25%–40%）。
- 钱塘云筑：线索量处于项目最高档，但成交转化率偏低。
- 滨江悦府：平均成交金额在四个项目中最高。
- 客户等级成交转化率排序：A > B > C。
- 置业顾问：负责线索量与成交转化率存在明显分化。

趋势由完整 18 个月序列和稳定统计规则验证，不依赖单月极端值。

## 重新生成

在项目根目录运行：

```powershell
python demo/generate_real_estate_sales_demo.py
```

生成器只使用 Python 标准库，固定随机种子为 `202509`。相同版本脚本每次
都会产生字节一致的 CSV。
