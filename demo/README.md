# 析数演示数据

`learning_operations_demo.csv` 是由仓库内
`generate_learning_operations_demo.py` 完全生成的合成数据。它不读取、
复制或转换任何现有 Excel、CSV、数据库或用户记录。

## 公开与隐私声明

- 数据为完全合成数据。
- 数据不对应任何真实个人、机构或业务。
- 数据仅用于“析数”的产品演示和自动化测试。
- 数据允许随本项目公开展示、复制和分发。
- 数据中不包含姓名、学员编号、年龄、城市、职业、联系方式或反馈文本。

## 数据规模与字段

数据固定为 360 行、9 列，覆盖 2025-01 至 2026-06 共 18 个自然月。
字段与 `app/v2/domain/learning_registry.py` 一致：

| 字段 | 含义 | 缺失规则 |
|---|---|---|
| 课程类别 | 课程所属方向 | 不允许缺失 |
| 课程难度 | 入门、进阶或高级 | 不允许缺失 |
| 购买渠道 | 获客渠道 | 不允许缺失 |
| 主要学习设备 | 主要设备平台 | 不允许缺失 |
| 报名日期 | ISO 格式报名日期 | 不允许缺失 |
| 实付金额 | 合成人民币支付金额 | 不允许缺失 |
| 课程完成率 | 0 至 1 之间的完成比例 | 不允许缺失 |
| 是否退款 | `是` 或 `否` | 不允许缺失 |
| 课程评分 | 1 至 5 分 | 允许少量合成缺失值 |

## 预设趋势

- 数据分析：月度报名数量整体增长。
- 前端开发：月度报名数量整体下降。
- 商业分析：相邻月份报名数量存在明显波动。
- AI 应用：平均完成率低于其他课程类别。
- AI 应用：退款率高于其他课程类别。

趋势由完整 18 个月序列和稳定统计规则验证，不依赖单月极端值。

## 重新生成

在项目根目录运行：

```powershell
python demo/generate_learning_operations_demo.py
```

生成器只使用 Python 标准库，固定随机种子为 `20260806`。相同版本脚本每次
都会产生字节一致的 CSV。
