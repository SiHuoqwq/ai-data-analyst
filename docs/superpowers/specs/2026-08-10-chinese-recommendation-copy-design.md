# 中文推荐文案与分析输入提示设计

## 目标

将分析工作台中面向用户的英文推荐文案统一为自然中文，并把过于模板化的输入框提示改成更开放、口语化的表达。变更后保持现有推荐生成、受控意图、分析执行和页面布局不变。

## 文案

推荐卡片及其填入的问题使用以下受控模板：

- `Compare by {dimension}` → `按{dimension}比较`
- `How do key outcomes compare across {dimension}?` → `不同{dimension}的关键指标表现有何差异？`
- `Monthly {dimension} trend` → `{dimension}月度趋势`
- `How does {dimension} change by month using {date}?` → `按{date}月份查看{dimension}的变化趋势`

分析输入框占位文案：

- `输入课程组合比较或月度趋势问题…` → `你想从这份数据中了解什么？`

动态字段名仍来自经过安全处理的数据集字段；本次不改变字段选择、推荐数量、点击行为或可执行意图范围。

## 实现边界

- 后端仅修改可信推荐文案渲染器。
- 前端仅修改输入框 `placeholder`。
- 更新或补充测试，验证中文模板和占位文案。
- 不修改推荐算法、Provider 协议、分析计划、图表、样式或布局。
- 不在验证过程中自动提交分析问题；真实 DeepSeek 模式启动后由用户亲自操作。

## 验证

先新增或更新测试并确认其因旧文案而失败，再做最小实现使其通过。随后运行完整后端测试，以及前端测试、类型检查、Lint 和构建。最后在不打印密钥的前提下检查 DeepSeek 配置并启动真实模式，验证 `/health` 的 Provider 状态和前端可访问性。
