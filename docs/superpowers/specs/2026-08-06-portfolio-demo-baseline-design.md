# 求职演示基线设计

## 目标

为“析数”提供一条无需真实模型、可重复运行且可以公开的演示基线，同时为后续受控 DeepSeek 验收保留相同的数据和问题入口。

## 范围

- 在 `demo/` 内生成并提交完全合成的课程运营 CSV、生成脚本和公开说明。
- 合成数据只包含 `LearningDomainRegistry` 使用的 9 个字段，固定随机种子，覆盖 2025-01 至 2026-06。
- 在分析工作台提供课程组合比较、月度趋势两条快捷问题；点击只填充输入框。
- `/health` 返回经过白名单映射的 Provider 公共状态，前端据此显示 Fake 或 DeepSeek 模式。
- 将正式前端开发端口统一为 5174，并提供 Windows 演示启停脚本。
- 更新现有 README 和发布演示文档，不增加新的分析工作流或配置系统。

## 数据设计

数据生成器只使用 Python 标准库。每月生成确定数量的五类课程记录：数据分析随时间增加，前端开发随时间减少，商业分析在相邻月份间显著波动，AI 应用保持稳定规模但具有较低完成率和较高退款概率，产品设计作为稳定对照组。评分允许少量确定性缺失，其余字段不得为空。

原始 520×32 工作簿只作为此前资产审计对象，不作为生成器输入，不复制记录，不移动、不修改、不提交。

## 运行时 Provider 状态

后端根据实际 `settings.v2_provider` 返回：

- `fake`：`Fake`、`确定性演示/测试模式`
- `deepseek`：`DeepSeek`、`真实模型模式`
- 其他值：`unknown`、`Provider 配置异常`

响应不得包含 API Key、模型请求、Prompt、Base URL 或文件路径。前端只渲染后端返回的公共字段。

## Windows 演示脚本

`start-demo.ps1` 默认将 Provider 强制为 Fake，使用仓库外的临时数据库、上传目录、图表目录和 PID 状态文件，先执行迁移，再以隐藏窗口启动后端和 `frontend-v2`。只有显式 `-Provider DeepSeek` 才检查本地 `DEEPSEEK_API_KEY`；缺失或仍为示例值时立即失败，且不输出密钥。

`stop-demo.ps1` 只终止由状态文件记录且属于当前项目的进程树，不扫描或终止其他服务。

## 验证

- 数据契约测试验证结构、时间范围、缺失规则和整体趋势。
- API 测试验证 `/health` Provider 状态及敏感字段缺失。
- 前端测试验证 Provider 文案来自健康响应，以及快捷问题只填充、不提交。
- PowerShell 行为测试验证 Fake 默认值和 DeepSeek 缺少 Key 时的失败边界。
- 完整后端、发布就绪、compileall、前端测试/typecheck/lint/build全部通过后，使用临时运行目录完成 Fake HTTP 上传、分析、恢复和图表下载闭环。
