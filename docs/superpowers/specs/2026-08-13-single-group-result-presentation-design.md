# 单对象分组结果展示设计

## 目标

当非时间序列的分组分析只返回一个对象时，不再生成占满画布的单柱柱状图。系统应如实说明当前不存在组间比较条件，并用紧凑指标概览展示这一对象，同时保留汇总表供用户核验。

## 判定规则

- 仅作用于非时间序列的分组结果。
- `row_count < 2` 时不生成柱状图。
- `row_count >= 2` 时继续使用现有普通柱状图或 Top 10 横向柱状图规则。
- 月度趋势不按课程类别数量判断；只要聚合结果含多个时间点，仍按现有规则生成折线图。
- 空结果继续使用既有空结果错误处理，不由本规则处理。

## 后端行为

`ChartPlanner` 在读取结构化结果契约后，若结果没有时间维度且行数少于 2，返回空图表计划。执行器的 `chart_planning` 步骤允许图表数量为 0，且不创建 Chart Artifact。

汇总 Table Artifact、Evidence 和最终结论仍使用确定性结果，不改变业务计算和校验要求。

## 前端行为

`TableArtifactView` 对恰好一行的表格增加单对象展示：

- 标题：`单对象概览`
- 显示对象名称，例如 `AI 应用`
- 将数值字段以紧凑指标项展示，并沿用现有数值格式化规则
- 显示说明：`当前结果仅包含 1 个对象，无法进行组间比较。`
- 在概览下方保留原始一行汇总表

若单行表格没有可识别的数值字段，仍显示对象与边界说明，不伪造指标。

多行表格、空表、图表放大和其他 Artifact 维持现状。不进行整体页面重做。

## 可访问性与真实性

- 概览使用可读标题和状态说明，不仅依赖颜色传达含义。
- 不引入目标线、进度条或好坏颜色，因为当前没有目标值或对照组。
- 不将单对象指标描述为比较结论。
- 不改变 Evidence、PlanCompiler 或 pandas 计算。

## 测试

严格测试先行：

1. 后端失败测试证明单行非时间分组当前仍产生柱状图计划。
2. 修复后断言该计划为空，多行分组仍产生柱状图，时间序列仍产生折线图。
3. 执行器集成测试断言单对象运行保留 Table Artifact、没有 Chart Artifact，并正常完成。
4. 前端失败测试断言单行表格出现单对象概览、对象值、指标值和边界说明，且原表仍存在。
5. 运行完整后端、发布就绪、Python 编译，以及完整前端测试、类型检查、Lint 和构建。
6. 验证期间使用 Fake Provider，不调用真实 DeepSeek。
