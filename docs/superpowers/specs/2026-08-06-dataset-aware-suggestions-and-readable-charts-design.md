# 数据集感知问题推荐与高基数图表可读性设计

日期：2026-08-06

## 1. 目标

在不新增分析类型、不放宽 Evidence 校验、不改变确定性业务计算的前提下，解决两个求职演示体验问题：

1. 不同数据集进入分析工作台时始终显示相同的固定问题。
2. 多维组合结果把 50 个长标签铺在横轴，导致文字严重重叠。

本轮继续只支持 `group_comparison`（课程组合比较）和 `monthly_trend`（月度趋势）两类受控意图。

## 2. 设计原则

- 模型负责基于安全字段画像改写问题，不负责创造新的分析能力。
- 推荐问题必须经过 Schema、字段引用和 PlanCompiler 可执行性校验后才能展示。
- 模型不可用或输出不合格时，系统仍可用确定性模板完成推荐。
- 不向模型发送原始数据行、密钥、物理文件路径或其他敏感配置。
- 图表负责突出重点，表格负责保留完整结果。
- 所有业务数字继续来自 pandas 工具和当前 Run Evidence。

## 3. 数据集感知问题推荐

### 3.1 生成时机与缓存

- 分析工作台首次请求某个数据集版本的推荐问题时，后端检查缓存。
- 已存在有效缓存时直接返回，不重复调用模型。
- 缓存按数据集版本隔离；新版本需要重新生成。
- DeepSeek 模式下首次缓存未命中时允许一次推荐生成请求。
- Fake 模式不调用模型，始终返回确定性字段模板，并在响应中标明来源。

### 3.2 模型输入

模型只接收安全字段画像：

- 文件显示名；
- 字段名和推断类型；
- 字段缺失率及是否可用；
- 当前允许的两个意图及其字段角色约束。

模型不接收原始记录、样本值、物理路径、API Key 或运行日志。

### 3.3 模型输出

结构化响应最多包含两条推荐，每类受控意图最多一条：

- `intent_type`：只能是 `group_comparison` 或 `monthly_trend`；
- `label`：用于卡片标题；
- `question`：点击后填入输入框的完整问题；
- `referenced_fields`：问题使用的字段列表。

### 3.4 校验与降级

后端依次执行：

1. 严格 Schema 校验；
2. 意图白名单校验；
3. 引用字段必须存在于当前数据集版本；
4. PlanCompiler 必须能为当前数据集编译受控计划；
5. 问题不得包含路径、代码、SQL 或未支持工具请求。

任一步失败时丢弃对应推荐。若没有合格的模型推荐，则根据领域注册表和字段角色生成确定性模板；数据集不满足某类意图时不显示该类问题。推荐响应需要暴露 `source=model|template`，但不得暴露 Prompt 或模型原始响应。

### 3.5 前端行为

- 工作台加载数据集后请求推荐问题并显示加载占位。
- 展示一至两条通过后端校验的问题卡片。
- 点击卡片只填充输入框，不自动创建会话或启动 Run。
- 模型和模板推荐使用一致的交互；可用简短文案标明“AI 推荐”或“字段模板”。
- 推荐失败时显示可恢复提示，不阻止用户手工输入问题。

## 4. 高基数组合图表

### 4.1 选择规则

- 完整组合聚合和 Evidence 不变。
- 组合比较图默认只绘制 Top 10 重点组合。
- 优先使用 `identify_underperforming` 识别出的高报名、低完成率组合。
- 不足 10 项时，再从完整聚合结果按报名人数补足；去重后最多 10 项。
- 表格继续展示现有完整预览范围，并明确完整结果规模。

### 4.2 图形与标签

- 高基数组合使用横向条形图。
- 标签顺序为“课程类别｜课程难度｜购买渠道｜主要学习设备”。
- 对纯显示标签进行安全缩写或换行，但不得改变底层维度值和 Evidence 标识。
- 报名人数、百分比指标和评分继续按量纲拆图，不混用坐标轴。
- 图表标题明确包含“重点 Top 10”或实际展示数量。

### 4.3 边界

- 月度时间序列继续展示完整月份，不应用 Top 10 规则。
- 低基数单维分类图保持现有行为。
- “放大查看”继续使用同一图像；本轮不引入新的交互式图表库。

## 5. 接口与存储边界

新增一个面向数据集版本的只读推荐查询接口。其响应包含推荐 ID、意图、标题、问题、字段引用、来源和生成时间。缓存使用现有数据库迁移流程显式增加持久化结构，FastAPI 启动时不得自动迁移。

推荐生成失败应返回可区分的非敏感错误码；前端可选择模板降级或允许手工输入。任何模型诊断只保存脱敏错误类型，不保存完整原始响应。

## 6. 测试策略

### 后端

- DeepSeek 推荐结构化响应解析与字段校验；
- 不支持意图、虚构字段和不可编译问题被拒绝；
- 同一数据集版本缓存命中时不重复调用模型；
- Fake 模式完全不调用模型；
- 模型失败时确定性模板降级；
- 不兼容数据集只返回可执行问题；
- 组合图只使用 Top 10，优先异常组合并保持量纲拆分；
- 月度图不受 Top 10 规则影响。

### 前端

- 推荐加载、成功、部分可用、降级和失败状态；
- 不同数据集展示不同后端推荐；
- 点击推荐只填充输入框；
- 来源标识来自后端，不由前端猜测；
- 手工输入始终可用。

### 回归

- 完整 pytest、发布就绪检查和 Python 编译；
- 前端测试、类型检查、Lint 和构建；
- Fake 模式演示闭环；
- 在单独授权和调用预算下进行 DeepSeek 推荐验收。

## 7. 验收标准

- 两个字段画像不同且均兼容的数据集能得到内容不同、但意图仍受控的推荐问题。
- 刷新同一数据集不会再次产生推荐模型调用。
- 推荐问题均可通过 PlanCompiler 并实际启动对应 Run。
- Fake 模式不产生真实模型请求。
- 多维组合图最多展示 10 条清晰可读的横向标签。
- 页面完整表格、Evidence 引用和确定性计算结果不因图表精简而改变。
- 页面和持久化数据不包含 API Key、完整 Prompt、模型原始响应或物理文件路径。

## 8. 非目标

- 不新增第三种分析意图。
- 不支持任意行业、任意表格或任意自然语言问题。
- 不引入交互式图表库或重做整体 UI。
- 不让模型生成 Python、SQL、工具名称或最终业务数字。
- 不修改演示数据趋势或 Evidence 校验规则。
